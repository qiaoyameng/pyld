# :material-export: `jsonld.to_rdf()`

::: pyld.jsonld.to_rdf
    options:
      show_docstring_description: false

## Options

::: pyld.options.ToRdfOptions
    options:
      show_root_heading: false
      show_bases: false
      heading_level: 3

When `format` is not set, `jsonld.to_rdf()` returns a
[:material-library: RDFLib](https://rdflib.readthedocs.io/) `rdflib.Dataset`.
Set `legacyMode` to `True` to return the RDF.js-like dataset `dict` used by
PyLD versions lower than 4.

`legacyMode` only affects the unformatted return value. If `format` is set,
`jsonld.to_rdf()` returns the requested serialization.

### Tracing statements back to input locations

Set `sourceMap` to `True` to receive a `ToRdfResult` whose `dataset`
attribute is the same value `jsonld.to_rdf()` returns without the option and
whose `sourceMap` maps each emitted N-Quads statement line to the RFC 6901
JSON Pointers of the input locations that produced it. The main result, blank
node allocation, and statement content are unchanged.

A statement synthesized from several locations lists every contributing
pointer. Structural statements generated by `@list`, `@reverse`, compound
literals, and named graphs additionally carry a `container` naming the
construct that generated them.
